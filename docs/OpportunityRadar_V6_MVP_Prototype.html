Agent 工作原则

避免把 OpportunityRadar 做成一个“高级爬虫后台”。

1
用户给目标，不给关键词搜索策略是 Agent 的工作，而不是用户配置负担。
2
数据质量不过关，不生成假精确评分真实数据先过 Gate，再进入 Buyer Intelligence。
3
每个结论必须能回到证据评分 + 原因 + 来源，避免黑盒数字。
